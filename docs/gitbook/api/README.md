# API

**Not available yet.** There is no public API today — every interaction with Contraflow goes
through the web app directly.

A tenant/API integration layer (letting another platform — an ERP, an accounting app, a
marketplace — register invoices and receive settlement webhooks programmatically) is a proposed
internal design, not a built feature, and doesn't have a public timeline yet.

This page will be replaced with real endpoint documentation once that work exists — until then,
treat any description of specific endpoints, authentication, or webhook shapes attributed to
Contraflow as inaccurate.
